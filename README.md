# Virtual Economy

FastAPI-сервис виртуальной экономики: пользователи, каталог товаров, покупка за внутренний баланс и инвентарь.

Покупка проверяет, что пользователь и товар существуют, на балансе хватает средств, а постоянный товар не покупается второй раз. Инвентарь сначала читается из Redis. Если записи в кэше нет, сервис берёт данные из PostgreSQL и кладёт их в Redis. Celery по расписанию сбрасывает кэш инвентаря и обновляет кэш популярных товаров. Redis здесь и кэш, и брокер очереди Celery.

Стек: Python, FastAPI, PostgreSQL, Redis, Celery, Docker, pytest.

## Запуск

```bash
docker compose up
```

API: http://localhost:8000  
Документация: http://localhost:8000/docs

Поднимаются сервисы `web`, `db` (PostgreSQL), `redis`, `celery-worker` и `celery-beat`. При первом запуске, если образов ещё нет:

```bash
docker compose up --build
```

## Тесты

```bash
pip install -r requirements-test.txt
pytest
```

`pytest` проверяет покупку: списание цены с баланса, отказ при недостатке средств и отказ, если товар не найден. Отдельные тесты проверяют схемы данных и инвентарь. Для тестов используется SQLite, PostgreSQL для них не нужен.
